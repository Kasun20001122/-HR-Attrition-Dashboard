# 🎯 Unlocking HR Insights with Interactive Visualizations! 🎯

Presenting my HR Attrition Dashboard, designed to uncover key trends in employee turnover and retention using dynamic visualizations in Power BI.

## ✨ Features and Visuals :

- Clustered Column Charts to compare attrition trends by age, job roles, and more.
- Cards and Donut Charts for a clear overview of total employees, active employees, and attrition rates.
- Buttons and Slicers for easy navigation and filtering by gender.
- Clustered Bar Charts and Stacked Column Charts to break down attrition by department, education field, and job level.
